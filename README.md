# Resume Studio

Aplikasi React untuk membina resume yang boleh diedit, disimpan secara automatik dalam browser, dicetak atau dieksport sebagai PDF, dan dikongsi melalui link.

## Jalankan

```bash
npm install
npm run dev
```

Buka URL yang dipaparkan oleh Vite. Data editor disimpan menggunakan `localStorage`. Link share mengandungi data resume yang telah dienkod dalam hash URL, jadi tiada backend diperlukan untuk demo ini.
